🌿 IndorePlants. - Your Organic Indoor Sanctuary📝 Project OverviewIndorePlants. is a meticulously crafted e-commerce landing page designed for the indoor plant market. Unlike simple HTML/CSS projects, this site is built using a modern utility-first approach with Tailwind CSS, ensuring a highly optimized, fully responsive, and easily scalable codebase.Goal: To provide a premium, visually engaging storefront emphasizing natural aesthetics and wellness.Approach: Built with a Mobile-First strategy for optimal performance on all devices.🚀 Live DeploymentThe final project is seamlessly hosted on GitHub Pages. You can explore the live demo here:👉 View IndorePlants. Live✨ Distinguishing FeaturesFeatureDescriptionTechnical ImplementationAtomic StylingStyles are generated using a utility-first workflow, resulting in an extremely lightweight and unique output.css file.Tailwind CSS with npm run build (Purge/Minify).Fully ResponsiveFlawless adaptation across mobile, tablet, and desktop viewports, using Flexbox and Tailwind's responsive breakpoints.Tailwind's Utility Classes (sm:, lg:, etc.).Custom BrandingUnique typography is utilized to enhance the visual identity, moving beyond standard system fonts.Google Fonts (Jost & Lobster) and local font assets.Rich Content ModulesIncludes dedicated sections for Product Cards (Pricing), Customer Testimonials, and Subscription Forms.Semantic HTML5 structure.Professional IconsIntegration of a vast library of icons for social media and navigation elements.Font Awesome CDN for reliable loading.💻 Tech StackMarkup: HTML5Styling: Tailwind CSS (The core framework)Build Tool: Node.js / npm (Used for compiling and minifying CSS)Deployment: GitHub Pages📦 Local Development GuideTo run and customize this project, you need to set up the Tailwind CSS build environment.1. Clone the RepositoryGet the source code onto your local machine:Bashgit clone https://github.com/ahmed-adel23/planto_website.git
cd planto_website
2. Install DependenciesInstall Tailwind and other necessary packages via npm:Bashnpm install
3. Build the CSSThe final CSS file (output.css) is generated from input.css. This must be run before deployment:Bash# This command generates the final, production-ready, minified CSS
npm run build 
4. Run LocallyAfter the build step, simply open the main file in your browser:Bashopen index.html
