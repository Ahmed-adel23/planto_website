## 📝 Project Overview

**IndorePlants.** is a meticulously crafted e-commerce landing page designed for the indoor plant market. It's built using a modern **utility-first** approach with **Tailwind CSS**, ensuring an optimized, fully responsive, and easily scalable codebase.

## 💡 Key Features & Design Philosophy

- ✅ **Utility-First Styling:** Achieved rapid development and highly optimized performance using Tailwind CSS classes.
- ✅ **Fully Responsive:** Flawless adaptation across all viewports (mobile, tablet, desktop) using Tailwind's powerful breakpoints.
- ✅ **Custom Typography:** Integrated Google Fonts (**Jost** and **Lobster**) to create a strong and memorable visual identity.
- ✅ **Clean Codebase:** Semantic HTML5 structure with clear separation between markup and the compiled CSS.
- ✅ **Interactive Components:** Includes dedicated sections for Product Cards, Customer Testimonials, and Subscription Forms.

---

## 🛠️ Built With

- **HTML5:** Core page structure.
- **Tailwind CSS:** The primary framework for all styling and responsive design.
- **JavaScript (Vanilla JS):** For subtle interactivity and UI logic.
- **Font Awesome (CDN):** For scalable vector icons.
- **Node.js/npm:** Used exclusively for compiling and minifying the production CSS.

## 📦 How to Use Locally

To run and customize this project locally, you must first build the production CSS using Node.js/npm.

1.  **Clone the repository:**
    ```bash
    git clone [https://github.com/ahmed-adel23/planto_website.git](https://github.com/ahmed-adel23/planto_website.git)
    cd planto_website
    ```

2.  **Install dependencies:**
    ```bash
    npm install
    ```

3.  **Build the CSS** (Generates the final `output.css`):
    ```bash
    npm run build
    ```

4.  **View the project:**
    Open the generated `index.html` file in your preferred browser.
